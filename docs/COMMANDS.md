# 📱 Команды бота

## Основные команды

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню с интерактивными кнопками |
| `/status` | Проверить статус балансера и всех прокси-серверов |
| `/logs` | Показать последние логи балансера |
| `/stats` | Статистика CPU и Memory |
| `/restart` | Перезагрузить балансер (требует подтверждения) |
| `/help` | Справка по всем командам |

---

## 📊 Команда `/status`

Показывает статус всех серверов в системе:
📊 СТАТУС СЕРВЕРОВ

🔹 Балансер (1.1.1.1)
✅ работает

🔹 Proxy #1 (2.2.2.2)
✅ работает

🔹 Proxy #2 (3.3.3.3)
❌ недоступен

🔹 Proxy #3 (4.4.4.4)
✅ работает

text

**Возможные статусы:**
- ✅ работает — контейнер запущен и отвечает
- ⚠️ проблемы — контейнер запущен, но есть ошибки
- ❌ недоступен — сервер не отвечает или контейнер остановлен

---

## 📋 Команда `/logs`

Показывает последние 15 строк логов балансера:
📋 Логи балансера (последние 15 строк)

[2024-01-15 10:23:45] [Router] User: client, Target: ifconfig.me, Selected: proxy1
[2024-01-15 10:23:46] [Proxy] Connection established to ifconfig.me
[2024-01-15 10:23:47] [Router] User: client, Target: google.com, Selected: proxy2

text

**Использование:**
- Проверка ошибок подключения к прокси
- Отладка маршрутизации
- Мониторинг нагрузки

## 🔄 Команда `/restart`

Перезагружает балансер. **ВНИМАНИЕ!** При перезагрузке:

- Обрываются все активные соединения
- Клиентам нужно будет переподключиться
- Процесс занимает ~5-10 секунд

**Процесс:**
1. Бот запрашивает подтверждение
2. Если подтверждено — перезагружает контейнер
3. Отправляет уведомление о результате

---

## 🔐 Безопасность

- ✅ Только администратор может выполнять команды
- ✅ Все команды логируются в файл `logs/bot.log`
- ✅ Автоматические алерты при сбое серверов
- ✅ Подтверждение критических операций (перезагрузка)

---

## 🚨 Автоматические алерты

Бот автоматически проверяет состояние серверов каждые 5 минут и отправляет уведомление, если:

- Балансер недоступен
- Любой из прокси-серверов не отвечает

Пример уведомления:
🚨 АЛЕРТ! Балансер недоступен!

text

или
🚨 АЛЕРТ! Proxy #1 (2.2.2.2) недоступен!

text

## 💡 Примеры использования

### Быстрая проверка системы
1. Открыть чат с ботом
2. Отправить `/status`
3. Убедиться, что все серверы работают

### Отладка проблемы
1. Заметили, что сайт открывается медленно
2. Отправить `/logs` — посмотреть, какой прокси выбран
3. Отправить `/status` — проверить, живы ли все прокси

### Плановое обслуживание
1. Отправить `/restart`
2. Подтвердить перезагрузку
3. Дождаться уведомления о завершении
